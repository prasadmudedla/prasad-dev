An eval pipeline that runs against production with a dedicated test account. It tests the agent at three levels of tool use, each as a single message and as a longer conversation. An LLM judge scores the results, and browser evals check the whole experience end to end.

<EvalMatrix />

Around it, I built the pieces that make it useful day to day. Every failure is matched against bugs already reported, so only new problems reach triage. I tuned the description of every tool so the agent knows what each one does and when to call it. The test cases live as YAML in GitHub, so product managers add prompts themselves and every run leaves a report behind. Fixing what the evals caught lifted pass rates by 20–30%.

For Canva AI's big March release, I also helped design the system that gathered the flood of bug reports from every channel, sorted them by area and sent each one to the right team.
